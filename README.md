# Wild Coast Trails

Build a modern, responsive 4-page website for "Indlela Adventures", a community-based Wild Coast hiking tour company in South Africa. 

The website should feature a clean, professional, and ecotourism-focused aesthetic. Use an organic color palette: deep earth tones (forest/khaki greens, warm sandy beiges) paired with ocean blues, balanced by crisp white backgrounds for high readability. 

Please set up a global navigation header and a footer across all pages. The site needs the following 4 pages:

1. Home Page:

- A striking Hero section featuring a large title: "Indlela Adventures" and subtitle: "Community-based Wild Coast hiking tours in South Africa".

- Two prominent CTA buttons: a primary button "Plan your Wild Coast hike" and a secondary button "View hiking packages".

- An "Experience & Impact" section explaining how walking the pristine coastline supports local villages and prevents destructive mining.

- A "Why Hike With Us?" benefits section.

- A Testimonials grid placeholder section.

2. Hiking Packages Page:

- An introductory section explaining that tours are fully customizable.

- A visual "Popular Routes" showcase (displaying 3 nights, 5 nights, 9 nights, and 2 weeks options).

- A side-by-side interactive comparison table or card layout detailing the pricing packages: "Traditional Package (R1450/night)" vs "Comfort Package (R1800/night)".

- Clear callouts for available discounts (Winter and Large Group bookings).

- Special sections dedicated to School Trips and Corporate Retreats, plus a quick info block on Shuttle Services.

3. About Page:

- A split-screen or styled section for "Meet Your Guide" highlighting the founder Siyabonga Ndovela (Siya).

- A powerful "The Community" storytelling section detailing the ecotourism path ("Indlela") and its stand against industrial exploitation.

- A bold, emphasized callout statement at the bottom: "Indlela Adventures is not an outside tour operator running trips through this land. We are the land’s people, inviting you to experience it responsibly."

4. FAQs Page:

- A clean, modern interactive accordion menu component (click-to-expand) to house the common questions regarding safety, fitness, water, community support, gear carrying, and emergency procedures.

Ensure the typography is bold and modern for headings, and highly legible for body text. Use clean UI cards, icons, and beautiful layout placeholders where images will go so I can easily swap in my final assets and text blocks next.
